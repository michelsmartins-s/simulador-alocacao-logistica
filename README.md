# Sistema de Alocação de Carga & Gestão de Laudos Logísticos

## Contexto do Projeto

Este projeto é o Trabalho de Conclusão de Ano (TCA) do 2º ano do curso Técnico em Informática para Internet no IFRS — Câmpus Rio Grande.

A ideia surgiu por conta do trabalho do meu pai no setor de logística retroportuária em Rio Grande (RS). Me baseei nas vivências e na rotina dele com vistorias de containers, laudos de inspeção e documentos para identificar um problema real e aplicar os conteúdos que aprendi em aula.

Este trabalho dá continuidade e aprimora o TCA desenvolvido no 1º ano, que consistia em um algoritmo de backtracking em JavaScript para simulação de alocação de cargas. Para o 2º ano, pretendo refatorar o algoritmo para incluir restrições reais de peso e melhorias no desempenho através de poda, além de desenvolver um sistema web de gestão logística voltado para vistorias retroportuárias. O sistema gerencia processos, gera relatórios de inspeção e integra a simulação de cargas diretamente na interface
